# KlesLwR Classic (WPF)

**KlesLwR** is a gaming macro app for Windows — macros, keybinds, overlays, and tools built for competitive Roblox fighting gameplay.

This repository hosts **Classic WPF** release downloads (the full desktop build).

## What’s Classic WPF?

- Full feature set (~300 MB)
- Macro editor, overlays, cloud configs, and the classic desktop UI
- The original KlesLwR experience

## Download

Get builds from [Releases](https://github.com/Rofix033034/KlesLwRdesktopmacroupdates/releases), or from the official site:
